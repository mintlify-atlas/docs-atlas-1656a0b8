The Invoice API provides comprehensive endpoints for managing invoices, including CRUD operations, payment tracking, scheduling, and analytics.

## Query Endpoints

### get

Retrieve a paginated list of invoices for the current team.

<ParamField query="status" type="string" optional>
  Filter by status: "draft", "unpaid", "paid", "overdue", "canceled", "scheduled"
</ParamField>

<ParamField query="customerId" type="string" optional>
  Filter by customer ID
</ParamField>

<ParamField query="q" type="string" optional>
  Search query for invoice number or customer name
</ParamField>

<ParamField query="start" type="string" optional>
  Start date for filtering (ISO 8601)
</ParamField>

<ParamField query="end" type="string" optional>
  End date for filtering (ISO 8601)
</ParamField>

<ParamField query="sort" type="array" optional>
  Array of sort objects with field and direction
</ParamField>

```typescript
import { trpc } from '@/lib/trpc';

const invoices = await trpc.invoice.get.query({
  status: 'unpaid',
  start: '2024-01-01',
  end: '2024-12-31',
});
```

    <ResponseField name="amount" type="number">

    </ResponseField>
    <ResponseField name="currency" type="string">

    </ResponseField>
    <ResponseField name="issueDate" type="string">
      ISO 8601 timestamp
    </ResponseField>
    <ResponseField name="dueDate" type="string">
      ISO 8601 timestamp

</ResponseField>

```typescript

```

## Mutation Endpoints

### draft

Create a new draft invoice.

<ParamField body="id" type="string" required>
  UUID for the invoice (use defaultSettings to get one)
</ParamField>

<ParamField body="invoiceNumber" type="string" optional>
  Invoice number (auto-generated if not provided)
</ParamField>

<ParamField body="customerId" type="string" optional>
  Customer UUID
</ParamField>

<ParamField body="customerName" type="string" optional>
  Customer name if no customerId
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter currency code
</ParamField>

<ParamField body="lineItems" type="array" required>
  Array of line items
</ParamField>

<ParamField body="issueDate" type="string" required>
  Issue date (ISO 8601)
</ParamField>

<ParamField body="dueDate" type="string" required>
  Due date (ISO 8601)
</ParamField>

<ParamField body="template" type="object" required>
  Template configuration
</ParamField>

```typescript
const invoice = await trpc.invoice.draft.mutate({
  id: generatedId,
  customerId: 'customer-uuid',
  currency: 'USD',
  lineItems: [
    {
      name: 'Web Development',
      quantity: 40,
      price: 150,
      vat: 0,
    },
  ],
  issueDate: new Date().toISOString(),
  dueDate: addDays(new Date(), 30).toISOString(),
  template: templateSettings,
});
```

### create

Finalize and create an invoice from a draft.

<ParamField body="id" type="string" required>
  The draft invoice ID
</ParamField>

<ParamField body="deliveryType" type="string" required>
  "create" | "create_and_send" | "scheduled"
</ParamField>

<ParamField body="scheduledAt" type="string" optional>
  Required if deliveryType is "scheduled" (ISO 8601)
</ParamField>

<ResponseField name="data" type="object">
  The created/scheduled invoice object
</ResponseField>

```typescript
// Create immediately
const invoice = await trpc.invoice.create.mutate({
  id: draftId,
  deliveryType: 'create',
});

// Create and send
const invoice = await trpc.invoice.create.mutate({
  id: draftId,
  deliveryType: 'create_and_send',
});

// Schedule for later
const invoice = await trpc.invoice.create.mutate({
  id: draftId,
  deliveryType: 'scheduled',
  scheduledAt: '2024-12-01T09:00:00Z',
});
```

## Scheduling

### updateSchedule

Update the scheduled send date for a scheduled invoice.

<ParamField body="id" type="string" required>
  The scheduled invoice ID
</ParamField>

<ParamField body="scheduledAt" type="string" required>
  New scheduled date (ISO 8601, must be in the future)
</ParamField>

```typescript
await trpc.invoice.updateSchedule.mutate({
  id: invoiceId,
  scheduledAt: '2024-12-15T10:00:00Z',
});
```

### cancelSchedule

Cancel a scheduled invoice and return it to draft status.

<ParamField body="id" type="string" required>
  The scheduled invoice ID
</ParamField>

```typescript
await trpc.invoice.cancelSchedule.mutate({
  id: invoiceId,
});
```

## Time Tracking Integration

### createFromTracker

Create an invoice from time tracking entries.

<ParamField body="projectId" type="string" required>
  The tracker project UUID
</ParamField>

<ParamField body="dateFrom" type="string" required>
  Start date for time entries (ISO 8601 date)
</ParamField>

<ParamField body="dateTo" type="string" required>
  End date for time entries (ISO 8601 date)
</ParamField>

<ResponseField name="data" type="object">
  The created draft invoice with calculated hours and amount
</ResponseField>

```typescript
const invoice = await trpc.invoice.createFromTracker.mutate({
  projectId: 'project-uuid',
  dateFrom: '2024-11-01',
  dateTo: '2024-11-30',
});

// Invoice will have a line item with:
// - name: "Project Name (Nov 1, 2024 - Nov 30, 2024)"
// - quantity: total hours tracked
// - price: project hourly rate
```
